# API / Reference (example)

## HTTP `/api/skills/{id}`

- `resource_path`: Relative path in the package, for example `FORMS.md`, `scripts/payloads.txt`.
- `depth=summary`: Summary and Directory Only, Fit to First Track.

## Multi-agent running time

- Use Eino ADK **`skill`** Tools progressively loaded by skill pack; Optional Open `multi_agent.eino_skills.filesystem_tools` Access package files.
